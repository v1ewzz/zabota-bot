# Zabota Bot

Бот + мини-приложение в мессенджере MAX для подбора мер поддержки семьям участников СВО.

## Назначение решения

Система помогает пользователю за 3–5 минут узнать, какие федеральные и региональные меры поддержки ему положены, и получить ссылки на подачу заявлений.

## Основной пользовательский сценарий

1. Пользователь открывает бота в MAX.
2. Проходит короткий опрос (статус, регион, состав семьи, ключевые параметры).
3. Система подбирает меры поддержки по правилам (rules-engine).
4. Пользователь видит карточки мер с суммами, основаниями, документами и ссылками на подачу.
5. При необходимости открывается мини-приложение «Личный кабинет» для отслеживания статусов.

## Состав и архитектура решения

- **backend/** — Java-приложение (Spring Boot):
  - webhook от MAX (чат-бот);
  - REST API для мини-приложения;
  - бизнес-логика и работа с БД.
- **frontend/** — React + TypeScript:
  - мини-приложение MAX «Личный кабинет»;
  - отображение мер поддержки и статусов.
- **database/** — PostgreSQL:
  - схема БД и миграции (заполняется отдельно).
- **docs/** — документация проекта.

### Схема взаимодействия

```text
MAX Chat Bot (webhook) ←→ Backend (Java)
                               ↓
                         PostgreSQL
                               ↓
MAX Mini App (React) ←→ Backend (REST API)
```

## Быстрый старт (Docker)

Одна команда для запуска всех локальных компонентов:

```bash
docker compose up --build
```

Детали настройки портов и переменных окружения будут добавлены по мере разработки.

## Переменные окружения

Скопируйте `.env.example` в `.env` и заполните значения:

```bash
cp .env.example .env
```

Не коммитьте `.env` с реальными токенами в репозиторий.

## Описание работы с данными

- Схема БД и миграции находятся в папке `database/`.
- Эта часть заполняется отдельным участником команды.
- Тестовые данные будут добавлены позже.

## Известные ограничения

- Интеграции с государственными системами (ЕГИССО, СФР, ФНС) в MVP — модельные, на основе публичных данных.
- Бот требует регистрации в MAX и получения токена.
