# Отчёт об аудите и дизайн-апгрейде — Zabota Mini-App (frontend)

## Логические баги (исправлены)
1. Отсутствующий `backend.requestMfc` — гарантированный краш в проде. Исправлено в `src/api/backend.js`.
2. Race condition в `updateSupport` (AppContext.jsx) — параллельные PATCH-запросы на одну меру
   могли применяться не в том порядке. Исправлено монотонным счётчиком запросов.
3. Race condition при размонтировании (`Results.jsx`) — устаревший ответ `runMatch` мог
   применяться после ухода со страницы. Исправлено через `AbortController` + `isMountedRef`.
4. Утечка обработчика кнопки "назад" (Layout.jsx) — cleanup снимал не тот обработчик.
5. Лишние вычисления на каждый рендер (`MeasureDetail.jsx`) — RegExp пересобирался при
   каждом рендере; вынесено в модульную константу + `useMemo`.
6. Неограниченный параллелизм сетевых запросов в `getUserSupports` — добавлен пул из 4 воркеров.
7. Тихая ошибка конфигурации `VITE_USE_MOCK=true` в проде — добавлено явное предупреждение.

## Дизайн — полный рерайт `src/styles/global.css`
Файл переписан с нуля (а не дополнен, как в первой версии) под единую дизайн-систему:

- **Типографика**: подключён Manrope (display-шрифт для заголовков/чисел, 800–900 вес) +
  Inter для основного текста — тот же приём, что использует большинство крупных
  продуктовых сайтов для контраста между "жирным" брендом и читаемым текстом.
- **Цвет**: более глубокая фиолетово-синяя фирменная палитра (`--brand-1/2/3`),
  многослойный radial-gradient фон на body вместо плоской заливки.
- **Тени**: единая система из 5 уровней (`--shadow-xs` … `--shadow-lg`, `--shadow-brand`)
  вместо одной плоской тени на всё — карточки, кнопки и модалки выглядят объёмно.
  на всё — карточки, кнопки и модалки выглядят объёмно.
- **Профильная карточка** (`.profile-card`) — теперь фирменная градиентная "обложка"
  с decorative radial-highlights, полупрозрачной статистикой и стеклянным аватаром,
  а не белая плоская карточка.
- **Hero-метрика результатов** (`.results-hero__num`) — крупное число 58px с
  градиентной заливкой текста (background-clip: text).
- **Микроанимации**: появление страницы (`page-in`), пружинный bottom-sheet (`sheet-up`),
  toast, shimmer-скелетоны, hover-лифт карточек мер, вращение loader'а.
- **Компоненты**: кнопки, чипы, табы, свитчи, choice-группы, статус-бейджи — везде
  добавлены aккуратные hover/active-состояния и единый focus-ring для доступности.
- Все структурные CSS-свойства (grid-template-columns, position:fixed/sticky, z-index)
  сохранены без изменений — вёрстка не сломана, менялся только визуальный язык.

`frontend/index.html` дополнен `<link rel="preconnect">` для Google Fonts.
