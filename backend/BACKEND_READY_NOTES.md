# Backend: готовая основа для расширения проекта «Забота»

## Что изменено

- Расширен `User` под новые параметры анкеты из V21.
- Расширен `UserChild` новым параметром типа учреждения.
- Расширены `UserRequest`, `UserResponse`, `UserChildRequest`, `UserChildResponse`, `SupportSearchRequest`.
- `SupportMatchingService` умеет учитывать новые параметры анкеты, включая параметры самого военнослужащего.
- `SupportMeasureResponse` теперь содержит связанные НПА с URL официального документа.
- `SupportMeasureService` обогащает ответы мерами связанными НПА.
- Добавлен endpoint `PUT /api/users/{id}/profile`, который сохраняет новую анкету и сразу запускает повторный подбор мер.
- Существующие endpoint'ы и совместимые сигнатуры mapper/service сохранены.
- Миграции V1–V26 перенесены в backend без изменения содержимого. В частности V21–V26 совпадают с исходными файлами побайтно.

## Миграции

Используются V1–V26. Новая миграция V27 не добавлялась.

## Ограничение проверки

Полный Maven compile/test в текущей среде не выполнен: Maven Wrapper попытался загрузить Maven 3.9.16 из Maven Central, но сетевой доступ к репозиторию в среде отсутствует. Исходники и структура backend проверены статически; это не заменяет локальную `./mvnw clean test` в окружении пользователя.
